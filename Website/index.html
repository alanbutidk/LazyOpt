LazyOpt is a program written in Python

It simplifies the average commands or Lazyify them

It stands for Lazy Options, LazyOpt is a multi-language project (Python & Go).
The file LazyOpt.py is the main file, it handles everything...

server.go is the server hoster, basically a gold mine server hoster!

How was it compiled

It was compiled with: (lazyopt.py) autobuild build. By the way, autobuild is a build system like make, Get it from github (Releases).
The server.go file was compiled with:
set GOOS=windows
set GOARCH=amd64
go build -o server.exe server.go

# LazyOpt
*LazyOpt* is a program made in *Python* that simplifes many things, Like:

+ Finding programs and files (not directorys)
+ Launching servers that actually *_work_*
+ Killing PIDs by name, universally!
+ Getting your PATH!

------------------

# Installation

Get the LazyOpt executable based on your OS & the server program!

Add it to your PATH and remember, *The server executable needs to be at the same location as the LazyOpt _Executable_*
